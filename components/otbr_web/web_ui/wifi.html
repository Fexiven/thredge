Wi-Fi band

The XIAO ESP32-C5 has one antenna shared between Wi-Fi and Thread. Wi-Fi on 5 GHz keeps the 2.4 GHz radio free for Thread; if the router uses one name for both bands (band steering), it may still put the device on 2.4 GHz -- forcing 5 GHz here overrides that.
