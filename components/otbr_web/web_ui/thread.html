Active dataset

These are the credentials of your Thread network. Paste them into Home Assistant or another border router so it joins this same mesh instead of forming a separate one. Treat them like a Wi-Fi password.


  


  
Join an existing network

  

    
Paste the network's active dataset. In Home Assistant
      that is Settings → Devices & services → Thread → the
      network's overflow menu → Download credentials; the long hex
      string is what goes here. JSON works too. This is the reliable way to
      join — a network key on its own is not enough, because Thread also
      needs the extended PAN ID and channel to attach.

    
    
    

      
    

    

  


  
Join by network key

  

    
If you only have the network key, this discovers the mesh and builds the
      rest of the dataset from what the scan reports. Less reliable than pasting
      the full dataset — the mesh-local prefix and commissioner
      credentials are left at their defaults, and the device picks them up from
      the leader once it attaches.

Form a new network

  

    
Creates a fresh Thread network on this router. Any devices already
      commissioned to the current network will stop reaching it, so only do this
      when you are starting over.
