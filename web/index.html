Turn an ESP32-C5 into a Thread Border Router

One chip bridges your Thread devices onto your home network — Wi-Fi on 5 GHz, Thread on the built-in 802.15.4 radio. Works with Home Assistant, Matter and anything that speaks Thread.

Plug the board into this computer with a USB data cable, then:

Your browser can't talk to serial devices. Open this page in desktop Chrome or Edge.

This page has to be served over HTTPS to flash a device.

Needs Chrome or Edge on desktop. Choose the board's serial port when asked.

  1. Install — the button above flashes the latest release over USB. Choose "Erase device" on a first install.
  2. Connect it to Wi-Fi — after flashing, the device broadcasts a network named ESP-ThreadBR-XXXX. Join it with your phone and a setup page opens (or visit http://192.168.4.1). Pick your home network — the 5 GHz one if you have it.
  3. Done — the border router starts and forms a Thread network. Manage it at http://esp-otbr.local — firmware updates live on the Update tab there.

Joining an existing Thread network

Running Home Assistant or another border router already? Copy your Thread network's active dataset (in HA: Settings → Devices → Thread) and paste it in the device's web interface so it extends your existing mesh instead of creating a new one.

Something not working?

If the serial port doesn't show up, try another cable — many USB-C cables are charge-only and carry no data lines. To start over, hold the BOOT button for five seconds — the setup network reappears. Bugs and questions: the project on GitHub.
